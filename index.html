📜 뽑기 기록

    ⚙️ random.org 연동 방식

    1. 1순위: /.netlify/functions/random → 서버에서 generateIntegers JSON-RPC 호출 (API 키는 Netlify 환경변수 RANDOM_ORG_API_KEY에 보관, 클라이언트 노출 없음)
    2. 2순위: https://www.random.org/integers/ 공개 API (키 불필요) 호출
    3. 3순위: 전부 실패하면 crypto.getRandomValues() 폴백 (화면에 소스 표기됨)

    출처 메뉴: subway.co.kr/menuList/sandwich (이미지도 공식 CDN 사용)
    Netlify 배포: 이 폴더 통째로 드래그-드롭 또는 GitHub 연결 → publish ., functions netlify/functions
